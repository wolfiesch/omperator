● new this cycle — cmux parity

fork
Branch any session into a full-history copy — from the rail row menu, the session menu, or the TUI (f). Official-host forking implemented end to end.
design mode
Annotate an element in the browser pane, add a note, and a structured prompt lands in the composer. One-shot, no auto-send.
gallery
The files pane shows real image thumbnails with a full-screen preview — after we fixed the host silently dropping large reads over remote.
unread
Accent dots on rail rows with new activity; ⌘⌥U cycles unread sessions on macOS.
mouse
Terminal mouse reporting verified — htop, vim, and lazygit take clicks and scrolls.
t4 tui
The whole product in a terminal: rail, live transcript, composer, fork — one self-contained binary.
